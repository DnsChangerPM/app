# 🛡️ DNS Changer — کامل‌ترین برنامه تغییر DNS اندروید

یک برنامه‌ی فوق‌العاده سریع، بهینه و **جامع برای تغییر DNS در اندروید** با فلاتر و کاتلین نیتیو که تمامی قابلیت‌های برترین DNS Changer های گوگل‌پلی (مثل DNS Changer by BGNmobi، Nebulo، Intra و AdGuard) را به‌صورت کامل، یکپارچه و بهینه‌سازی‌شده ارائه می‌دهد.

---

## ✨ قابلیت‌ها و امکانات کامل برنامه

### ۱. ⚡ تست پینگ و سرعت لحظه‌ای سرورها (DNS Speed Test & Ping Benchmark)
- **تست تأخیر و سرعت واقعی (UDP 53 و TCP)** با میلی‌ثانیه برای تمام سرورهای داخلی و شخصی.
- **انتخاب خودکار سریع‌ترین DNS (Auto Best DNS)** با یک کلیک.
- تفکیک رنگی پینگ سرورها (سبز: زیر ۶۰ms، آبی: ۶۰ تا ۱۳۰ms، زرد: ۱۳۰ تا ۲۵۰ms، قرمز: بالای ۲۵۰ms).
- تست تک‌سرور مستقیم از روی کارت هر سرور در صفحهٔ اصلی.

### ۲. 🌐 بانک جامع و دسته‌بندی‌شدهٔ سرورهای DNS
بیش از ۳۰ سرور منتخب جهانی و منطقه‌ای در ۵ دسته‌بندی مجزا با فیلتر و جستجوی لحظه‌ای:
- 🎮 **گیمینگ و رفع تحریم (Gaming & Anti-Sanction):**
  - Radar Game (رادار بازی)
  - Electro (الکترو)
  - Shecan (شکن)
  - 403.online (۴۰۳ آنلاین)
  - Begzar (بگذر)
  - Pishgam (پیشگام)
  - Shatel DNS (شاتل)
- ⚡ **پرسرعت و عمومی (Fast & General):**
  - Cloudflare (1.1.1.1 / 1.0.0.1)
  - Google Public DNS (8.8.8.8 / 8.8.4.4)
  - Quad9 DNS (9.9.9.9 / 149.112.112.112)
  - Cisco OpenDNS (208.67.222.222 / 208.67.220.220)
  - Control D (76.76.2.0 / 76.76.10.0)
  - Level3 / CenturyLink (4.2.2.1 / 4.2.2.2)
  - DNS.WATCH (84.200.69.80)
  - G-Core DNS (95.85.95.85)
  - Verisign DNS (64.6.64.6)
- 🛡️ **ضد تبلیغات و امنیت (Ad-Blocking & Security):**
  - AdGuard DNS (مسدودساز تبلیغات در کل گوشی)
  - Mullvad AdBlock DNS
  - CleanBrowsing Security
  - NextDNS
  - LibreDNS
- 👨‍👩‍👧 **خانواده و جستجوی امن (Family & Safe Search):**
  - Cloudflare Family 1.1.1.3 (مسدودسازی محتوای نامناسب و بدافزار)
  - AdGuard Family Protection
  - CleanBrowsing Family Filter
  - OpenDNS FamilyShield
- ⚙️ **DNS شخصی و سرورهای اشتراکی (Custom & Subscription)**

### ۳. 📱 فیلتر پیشرفته برنامه‌ها (Per-App Split Tunneling)
- **حالت همهٔ برنامه‌ها (All Apps):** اعمال DNS روی کل ترافیک سیستم.
- **حالت Whitelist (فقط برنامه‌های انتخابی):** اعمال DNS تنها روی بازی‌ها یا برنامه‌های تیک‌خورده.
- **حالت Blacklist / Bypass (استثنا کردن برنامه‌ها):** عبور مستقیم برنامه‌های بانکی یا خاص بدون تغییر DNS.
- **حالت تک‌برنامه (Single App Focus):** مناسب بازی‌های خاص مثل `com.tencent.ig`.
- دکمه‌های انتخاب سریع بازی‌ها، مرورگرها و جستجوی نام پکیج.

### ۴. 📊 آمار لحظه‌ای و لاگ درخواست‌ها (DNS Stats & Query Log)
- تایمر زندهٔ مدت‌زمان اتصال (ساعت : دقیقه : ثانیه).
- شمارندهٔ تعداد درخواست‌های استعلام‌شده در نشست جاری و کل تاریخچه.
- لاگ درخواست‌های اخیر (Query Log) شامل دامنه، سرور پاسخ‌دهنده، زمان استعلام و تأخیر بر حسب ms.
- ذخیره‌سازی کاملاً آفلاین و محلی بدون ارسال هیچ‌گونه اطلاعات به خارج از دستگاه با امکان پاک‌سازی سریع.

### ۵. ⚡ کاشی تنظیمات سریع اندروید (Quick Settings Tile)
- اتصال و قطع سریع DNS مستقیماً از منوی کشویی اعلان‌های اندروید (`TileService`) بدون نیاز به باز کردن برنامه.
- همگام‌سازی لحظه‌ای وضعیت فعال/غیرفعال با رنگ و عنوان کاشی.

### ۶. 🛠️ ابزارهای شبکه و عیب‌یابی (Network Tools & Anti-Leak)
- نمایش نوع اتصال فعال (Wi-Fi، دیتای سیم‌کارت، اترنت)، آی‌پی محلی و دی‌ان‌اس‌های متصل.
- ابزار استعلام دستی دامنه (DNS Lookup Test) برای بررسی آی‌پی‌های پاسخ‌داده‌شده و پینگ هر دامنه دلخواه.
- سیستم ضد نشت DNS (Anti-DNS-Leak) با هدایت کامل ترافیک UDP/TCP پورت ۵۳ درون تونل امن.

### ۷. 🔄 پشتیبان‌گیری و بازیابی (Backup & Restore)
- خروجی گرفتن از تمام سرورهای شخصی در قالب فایل/متن استاندارد JSON.
- بازیابی و ورود پروفایل‌های ذخیره‌شده از کلیپ‌بورد یا فایل با اعتبارسنجی خودکار.

### ۸. ⚙️ تنظیمات و بهینه‌سازی پیشرفته
- کلید روشن/خاموش **پشتیبانی از IPv6** (جلوگیری از افت سرعت در اپراتورهای دارای IPv6 ناپایدار).
- **اتصال مجدد خودکار** هنگام سوئیچ بین Wi-Fi و دیتای سیم‌کارت.
- **اتصال خودکار پس از روشن شدن دستگاه (Auto-Connect on Boot)**.
- تنظیم مهلت زمانی پاسخ دی‌ان‌اس (DNS Query Timeout).
- طراحی مدرن **Material 3 Dark Theme** با دکمه‌ها و المان‌های نئونی جذاب.
- پشتیبانی کامل از زبان‌های فارسی و انگلیسی.

### ۹. 🔒 بخش اشتراکی و پنل ادمین کلودفلر (Cloudflare Admin Panel)
- امکان فعال‌سازی لایسنس اشتراک اختصاصی با اتصال به Cloudflare Workers + KV.
- مدیریت تعداد دستگاه‌های متصل، تاریخ انقضا و بن لحظه‌ای دستگاه یا لایسنس.
- به‌روزرسانی اجباری و دانلود داخلی APK از GitHub Releases با درصد واقعی.
